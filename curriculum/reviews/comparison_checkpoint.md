# Comparison checkpoint audit

Local review of lessons 001–004 after the counting-foundation checkpoint.
This is a content and code audit, not an observed first-time learning test.

| Finding | Change |
| --- | --- |
| 002–004 omitted explicit prerequisites | Declare counting through 20, pairing, and the previous comparison lesson in both languages. |
| 001 used “say one number” and “outlined pair” | Use touching each dot once and show one blue dot with one red dot as a pair. |
| Equation choices preceded explanation of symbols | Explain minus, equals, and the spoken equation before the first equation choice. |
| Transfer required unfamiliar quantities beyond 20 | Keep transfer prompts and choices within the taught range. |
| Temperature introduced an unexplained unit and larger numbers | Use a new score-comparison context with 18 and 10. |
| 004 introduced a long abstract description | Begin with the concrete Mia/Noah story and its question. |

The full screen order and stable screen IDs remain intact. Content revisions
increase so earlier completion does not silently certify revised instruction.
Generated memory assets are rebuilt from the revised curriculum.

Remaining limits: pairing is a model for comparing counts, not a universal
definition of subtraction. Count-up strategies elsewhere in the lessons still
need direct demonstration before being relied on as instruction. Some distractors
in earlier checks exceed 20; those should be reviewed in the next targeted pass.
The uniform phrase-meaning cards in lesson 004 remain potentially ambiguous
because individual statements have different roles. The earlier lesson audit
tests are structural checks, despite names that refer to novice understanding.
Do not interpret their passing status as proof of comprehension.

Mobile layout, spoken directions, Spanish accuracy, and learner responses
must still be checked on a published build. Publication remains blocked by the
previously rejected browser commit action and unavailable Git credentials.
