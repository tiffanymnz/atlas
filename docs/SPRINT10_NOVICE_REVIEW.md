# Sprint 10 novice review

## Decision

Lessons 010–011 are working prototypes, not production-approved curriculum. They remain marked `adult_review_required` until first-time adult learners can reconstruct inclusive bounds without coaching.

## Internal novice audit

The implementation addresses predictable barriers:

- each phrase begins with a familiar practical rule before technical vocabulary or symbols;
- the exact boundary is tested before the number-line direction;
- the number-line point and arrow communicate separate decisions;
- every wrong answer maps to boundary exclusion, reversed direction, boundary-only reasoning, or keyword-only symbol selection;
- strict inequalities appear only as a boundary showing where the inclusive reconstruction stops applying.

This audit checks the lesson contract. It does not satisfy the human observation gate.

## Human observation gate

Do not define minimum, maximum, inclusive boundary, or either inequality symbol during the attempt. Record hesitation and reasoning, not only selected answers.

After Lesson 010, ask the learner to:

1. explain whether the exact minimum qualifies;
2. test one value below and one above the boundary;
3. draw the allowed values without first writing a symbol;
4. explain why `≥` includes equality.

After Lesson 011, ask the learner to:

1. explain whether the exact maximum qualifies;
2. test one value below and one above the boundary;
3. draw the allowed values without first writing a symbol;
4. contrast `no more than` with `at least` in a new context.

Revise immediately if a screen requires undeclared prior knowledge. Revise when two learners expose the same misleading cue, symbol confusion, number-line problem, or translation issue.

## Remaining questions

- Does the closed point remain visually distinct on a small phone and in forced colors?
- Do learners treat the arrow as all allowed values rather than movement instructions?
- Does testing the boundary reduce symbol reversal after the visual is removed?
- Do the paired phrases feel meaningfully different without becoming a memorized minimum/maximum substitution rule?
- Which Spanish phrase is most natural in each context: `por lo menos` or `como mínimo`, and `no más de` or `como máximo`?
